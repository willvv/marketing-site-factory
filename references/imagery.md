# Imagery - everything is made by the image model

**Every image for the site and its social accounts is produced by the image model through the
`chatgpt-imagegen` CLI - text and logo included.** Covers, avatars, hero art, share/OG cards,
icons, diagrams, mockups.

## The rule, and why

- **Do not** build an image as HTML, SVG or canvas and screenshot it (Playwright, Puppeteer,
  headless Chrome).
- **Do not** generate a background and then add words or the logo on top in code. That is the
  same thing by another route.
- **If the model gets a word wrong or the logo drifts, fix it by prompting**: put the exact
  text in quotes in the prompt, pass the real logo as a reference (`refs`), say what to keep,
  regenerate. Do not reach for code to draw the missing part.
- *Not covered*: the site's own pages and components, and tiny functional UI glyphs
  (hamburger, close, chevron) written as CSS or inline SVG in `currentColor`. Those are code.
- **Allowed mechanical step**: cropping/resizing a generated image to a required size
  (`npm run images:fit`: 1200x630 share card, 512 favicon, 180 touch icon). It never draws.

## No emoji. Icons are generated.

Emoji as icons is the clearest tell of an AI-made site; stock icon fonts used as decoration are
the second. Instead generate an **icon set** with one shared style prompt so the icons match the
brand and each other:

```json
{
  "style": "Flat single-colour icon, 4px rounded line weight, brand colour #0B5FFF only, no gradient, no shadow, centred on a transparent background, generous padding, no text.",
  "images": {
    "icon-delivery": { "prompt": "A delivery box with a location pin.", "size": "1024x1024", "background": "transparent" },
    "icon-quote":    { "prompt": "A speech bubble containing a check mark.", "size": "1024x1024", "background": "transparent" }
  }
}
```

- Same `style` string for the whole set; change only the subject sentence.
- `background: "transparent"` is a codex-backend option (the default backend here).
- Generate at 1024, export to the size needed (usually 96-128 px displayed; ship WebP/PNG at 2x),
  give decorative icons `alt=""` and meaningful ones real alt text, always set `width`/`height`.
- Record the style string and every subject prompt in `BRAND.md`.

## Running it

```bash
node <skill-dir>/scripts/gen-images.mjs images.json            # fills gaps only
node <skill-dir>/scripts/gen-images.mjs images.json hero --force
```

Serial, ~20-60 s per image. The manifest is committed: it is what makes the visual language
reproducible and extendable. Manual single image:

```bash
PYTHONUTF8=1 python <path-to>/chatgpt-imagegen "<prompt>" --backend codex --size 1024x1024 --format png -o out.png
```

Useful flags: `--ref <file>` (image-to-image; use it for the real logo or a real photo),
`--ref-role subject|style|composition`, `--background transparent`, `--size 1536x1024` for
landscape.

### Windows

The CLI imports POSIX-only `fcntl` at start-up. `scripts/winshim/fcntl.py` supplies the one
function it uses; `gen-images.mjs` puts it on `PYTHONPATH` automatically (and sets
`PYTHONUTF8=1`, because the CLI prints characters cp1252 cannot encode). If you run the CLI by
hand, do the same.

### Failure table

| Message | Fix |
| --- | --- |
| `~/.codex/auth.json not found` | `npm i -g @openai/codex && codex login` |
| `no ChatGPT OAuth access_token` | only an API key is present - `codex login` with ChatGPT sign-in |
| `HTTP 400 requires a newer version of Codex` | `npm i -g @openai/codex@latest` |
| `refresh_token is no longer valid` | `codex login` again |
| `chatgpt-imagegen doctor` | read-only report of which backend is usable |

## The share / OG card (1200x630)

Built from the site's own logo and palette, **generated by the model**, committed.

1. Prompt for a card at `--size 1536x1024` that includes the **exact** business name and
   tagline in quotes, passes the real logo via `refs`, uses the brand palette, and keeps all
   text and the logo inside the **central 80 %** (the crop to 1.91:1 will trim top/bottom).
2. Save as `src/assets/brand/og-source.png`, then `npm run images:fit` ->
   `public/og-default.png` at exactly 1200x630.
3. **Look at the result.** Check spelling and that the logo did not drift; if not, fix the
   prompt and regenerate.
`SEO.astro` declares `og:image:width/height` = 1200/630 for the default card only, so the file
must match - `check-site.mjs` verifies the PNG header.

## Logo

- Business has one: use it **as-is**; pass it through `refs` when other images must include it.
  Never hand-redraw it.
- Business has none: generate one, and state in `BRAND.md` that it is generated (so the client
  can replace it).
- Keep the source file in `src/assets/brand/`; export a favicon from the icon mark
  (`icon-source.png` -> `favicon.png`, `apple-touch-icon.png`).

## Prompt craft that holds a set together

State medium, palette (with hex), lighting, composition and what to avoid in a shared `style`
sentence; keep subjects concrete; never ask the model to include real people's likenesses or
invented brand marks; describe real products from the client's own photos via `refs` rather than
inventing them (a stock-looking invented dish is a content-integrity problem).
